# 13.2 实验 F2：F 三状态解析接入在线双轮（3072）

## 目的

F0 已证 F 解析在离线同一批响应上安全 + 有局部收益。F2 验证 F 接入**正式求解路径**
后，不会因候选选择、条件重试、fallback 变化造成在线回退——这是把 F 固定为后续
token 实验基线的必要前提。

## 配置（单变量：只接入 F，其余与 C2+D 基线一致）

- C2+D Prompt（已回退实验 E）；F 三状态行解析（`parse_structure_f` 接入答案抽取
  与 `reconstruct_final_response_f` 接入 final_response 重建）；temperature=0.6；
  max_tokens=3072；workers=3；P2/P3 关闭；至多一次条件重试。

## F 解析 Gate（通过）

| 门槛 | 结果 |
| --- | --- |
| 元分析/约束说明识别为答案 | ✅ 0（行级收紧 + 单测覆盖） |
| 占位符识别为答案 | ✅ 0 |
| 有真实结构时答案/正文非空 | ✅ F0 已证 29/29 |

## 无回归 Gate（通过，且有明确收益）

- **derivation 两轮合并 90.0%（18/20），显著高于基线 70%**，超过 80% 门槛 ✅
  —— F 行级收紧修正了 C2+D 把 thinking 复述当答案的误判（F0 定位的 6003 类），
  使推导题答案抽取更准。
- 宏平均 62.2% / 59.4%（基线 61.7%），波动区间内，无稳定回退 ✅
- fill_blank 100% 稳定；choice/calculation 的 83.3% 是各 1 题模型随机波动
  （F 不碰数值题型解析路径，`extract_final_answer` 代码未变），非 F 导致 ✅
- 有效证明正文未截断/误删（F0 已证 body 非空 29/29，在线继承）✅

## 两个需记录的观察（不影响 F 晋升）

1. **R2 有 1 题 fallback（6037，calculation）**：两次调用都失败，导致 invalid_rate
   2.1% > 2% 门槛（G1=False）。这是**数值题型**的模型失败，与 F 无关。
2. **no_answer_block 仍集中在 length 截断**：R1 的 6002、R2 的 6000（derivation）
   两次调用都 length 截断，条件重试救不回——印证 F0 结论：这是 token 预算问题，
   F 解析解决不了，需要 4096 验证。

## 结论：F 安全晋升，可作 4096 实验基线

- F 接入无回归、有局部收益（derivation 70%→90%），解析 Gate 全过。
- 污染仍 >5%（thinking 泄漏 22.9–27.1%），根因在 length 截断的正文内部 self-check，
  不在解析层。
- **F + 3072 可固定为 3072 vs 4096 实验的基线**：3072 直接复用 F2 双轮，4096 再跑
  两轮即可，无需重复制造 3072 轮次。
