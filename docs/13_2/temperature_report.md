# 13.2 阶段 4：temperature 单变量 A/B（0.6 vs 0.2）

## 实验目的

C2+D 落地后，`final_response` 残余 12.5–20.8% 的 thinking 污染，根因是模型端
25–35% 的 thinking 泄漏。本实验验证 temperature 是否是泄漏的可调杠杆：
`0.6`（当前基线）vs `0.2`（官方示例值），其余单变量保持一致。

## 运行参数（显式值）

| 参数 | 值 |
| --- | --- |
| `max_tokens` | 3072（显式） |
| `policy_temperature` | 0.6 / 0.2（**显式传入**，脚本 `--temperature`） |
| workers（本地并发） | **3**（对齐官方评测并发） |
| retry | 3（网络退避，非求解重试） |
| Prompt / 抽取 / 重试 / P2/P3 开关 | 与 C2+D 完全一致 |
| 数据集 | 冻结集 48 题（两档各双轮） |

> 说明：此前 C2+D 基线用 workers=4 跑。为做严格单变量对照，本实验把 0.6 与
> 0.2 都在 workers=3 下重跑，两档并发一致。

## 结果（冻结集 48 题，双轮）

| 指标 | 0.6 R1 / R2 | 0.2 R1 / R2 |
| --- | ---: | ---: |
| thinking 泄漏率 | 29.2% / 25.0% | **35.4% / 25.0%** |
| final_response 污染率 | 16.7% / 12.5% | 18.8% / 18.8% |
| length 率（主调用） | 33.3% / 27.1% | 37.5% / 29.2% |
| 整体准确率 | 50.0% / 58.3% | 52.1% / 52.1% |
| 平均调用 | 1.02 / 1.02 | 1.02 / 1.00 |
| P95 输出 token | 3072 | 3072 |
| 平均延迟 | 25.6s / 25.5s | 22.5s / 20.0s |

### 题型宏平均（两轮合并）

| 题型 | 0.6 | 0.2 |
| --- | ---: | ---: |
| choice | 91.7% | 91.7% |
| fill_blank | 100% | 100% |
| calculation | 91.7% | 91.7% |
| derivation | 85.0% | 80.0% |
| proof | 0% | 0% |
| explanation | 5.0% | 0% |
| **宏平均** | **62.2%** | **60.6%** |

## 结论：temperature 不是 thinking 泄漏的根因

1. **0.2 没有降低泄漏**：第一轮 0.2 的 thinking 泄漏 35.4%，反高于 0.6 的
   29.2%；第二轮两档同为 25.0%。两档泄漏都波动于 25%–35%，说明 thinking 泄漏
   是模型对 derivation/proof/explanation 三类 Prompt 的**固有行为**，与采样温度
   无关。
2. **0.2 没有准确率收益**：宏平均 60.6% vs 62.2%（−1.7pp，处于波动区间内，
   无统计显著差异，也**没有任何正向证据**）。
3. **0.2 仅延迟略低**（20–22.5s vs 25.5s），但不是本次要优化的目标。

## 决策：保持 temperature=0.6 现状

按阶段 4 锁定的晋升门槛——「0.2 提高稳定性且没有准确率回退，才考虑作为默认值」，
0.2 未达门槛（未提稳、宏平均略降），**不晋升，`policy_temperature` 保持 0.6**。

## 对后续路线的影响

- temperature 已被排除为 thinking 泄漏的治理杠杆。泄漏治理仍只能回到
  **Prompt 协议层**（更强/不同的压制语或输出协议），或承认它是 InternLM 对
  「完整推导/证明/解释」类指令的固有行为，转而在**抽取/重建层**做更鲁棒的
  识别（C2 方向已部分覆盖）。
- **3072/4096 token 实验（阶段 5）的启动条件仍未满足**：其前置条件是「C2/D
  已解决伪标记与 thinking 前缀」，而当前 thinking 泄漏仍 25–35%、final_response
  污染 12.5–18.8%。在泄漏未解决前提高预算，只会让 thinking 泄漏得更久，不解决
  根因，故暂不启动 4096。
- proof/explanation 的 0% 仍是 judge 层「命题成立；…=X」中文结论前缀不适用本地
  端点判分（实验 C 已定位），与 temperature 无关，维持「不做局部数值剥离」的
  决定。
