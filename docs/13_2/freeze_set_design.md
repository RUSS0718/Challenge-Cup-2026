# 13.2 复杂能力冻结集设计规格

日期：2026-08-14
状态：设计定稿（题目生成前）
数据文件：`sample_data/complex_capability_freeze_48.jsonl`

## 1. 目的

`public_regression_112.jsonl` 的 112 题全部被 `classify_problem_type` 识别为
`calculation`，只能证明短计算题的知识覆盖与基础输出链路，**不能证明**证明、
推导、解释、长题面、跨方向混合题或 P3 验证/修正的收益（AGENTS.md）。

本冻结集补上这一块：覆盖 6 题型 + 长条件 + 跨方向，用于在 3072 基线上发现
**跨题型的系统性缺陷**，作为后续是否重新开启规范化 / Prompt / P3 的决策依据。

## 2. 规模与分布（48 题）

| 题型 | 数量 |
|---|---:|
| choice（选择） | 6 |
| fill_blank（填空） | 6 |
| calculation（复杂计算） | 6 |
| derivation（推导） | 10 |
| proof（证明） | 10 |
| explanation（解释） | 10 |
| **合计** | **48** |

附加约束：

- 长条件题（题干含 ≥3 个独立条件/参数，`is_long=1`）**≥ 12** 题。
- 跨方向题（涉及 ≥2 个数学方向，`subject` 用 `;` 分隔，`is_multi_domain=1`）**≥ 12** 题。

## 3. 来源（分两个集）

用户决策：**公开教材改编 + AI 生成，分成两个集**，混合进同一份冻结文件。

| 集 | 数量 | `source` 取值 | 说明 |
|---|---:|---|---|
| 公开教材改编集 | 24 | 沿用 112 题的 `source_id`（如 `mit_ocw_18_06`） | 从公开教材定理/公式改编为证明/推导/解释/计算，来源可审计 |
| AI 生成集 | 24 | `ai_generated` | 直接构造（选择/填空/复杂计算/跨方向混合），`source_url`/`source_ref` 留空 |

隔离：两个集均**不与** `public_regression_112.jsonl`、`dev.jsonl` 的题目或
`source`+具体参数重叠。

## 4. 判分约定（可判定结论设计）

用户决策：**可判定结论设计**。即尽量把答案设计成能被 `judge_correct` 判定的
数值 / 代数表达式 / 选项字母，避免文本答案落 unknown。

| 题型 | 答案形式 | judge 路径 |
|---|---|---|
| choice | 单个选项字母 | Level 1/2（字母） |
| fill_blank | 数值/代数 | Level 1/2/3（有理数 + SymPy） |
| calculation | 数值/代数 | Level 1/2/3 |
| derivation | 推导出的代数式/数值 | Level 3（SymPy 等价） |
| proof | 可判定的数学结论（如"证某等式成立"→ 等式两端；"证某数是根"→ 该值） | Level 1/3 |
| explanation | 解释的最终可判定结论（如"说明为何 =X"→ X） | Level 1/3 |

例外：允许 **≤5 题**纯命题证明/解释（如"证明 √2 无理"），`answer` 写命题结论，
judge 会判 `unknown`；报告单独标注这些题，人工复核。这是刻意保留的"真实复杂
能力"探针，不追求 100% 自动判。

## 5. 字段约定

每行 JSON（与 112 题对齐 + 冻结集专有标签）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `idx` | ✅ | int，从 6000 起（避开 112 题的 5000 段与 dev 的 0 段） |
| `problem` | ✅ | 题干（含选项/填空下划线等格式信号） |
| `answer` | ✅ | 标准答案（可判定结论） |
| `task_type` | ✅ | 期望题型（choice/fill_blank/calculation/derivation/proof/explanation），用于报告分组与分类一致性校验 |
| `subject` | ✅ | 数学方向；跨方向用 `;` 分隔 |
| `source` | ✅ | 教材 `source_id` 或 `ai_generated` |
| `source_url` | ⚠️ | 教材集必填；AI 集留空 |
| `source_ref` | ⚠️ | 教材集建议填（讲次/章节）；AI 集留空 |
| `adaptation` | ✅ | 改编说明（教材集）或 `ai_generated_original` |
| `verification` | ✅ | 独立验算式/代回/枚举依据 |
| `is_long` | ✅ | 0/1，是否长条件 |
| `is_multi_domain` | ✅ | 0/1，是否跨方向 |

## 6. 固定规则（冻结后）

- 固定后**不增删题目、不按单题结果调 Prompt**（AGENTS.md）。
- 默认路径晋升须在适用数据集上完成至少**双轮独立 A/B**。
- 校验脚本 `scripts/validate_freeze_set.py` 每次改动后重跑，保证分布/隔离/字段不变。

## 7. 报告指标

两轮纯基线（当前 3072 默认配置，不改任何开关）跑完后，报告：

- 题型宏平均准确率（按 `task_type` 分组，未知题如实标注）
- 主调用 length 率（按题切片）
- 答案标记覆盖率（1 − 条件重试率）
- 平均/P95 模型调用数、总调用数
- 平均/P95 延迟
- fallback 数
- 失败类别（无答案 / 占位符 / 抽取失败 / 未知-表示不一致 / 未知-纯命题）

## 8. 决策规则（已锁死）

1. 表示问题在冻结集**跨 ≥3 个独立样本**重复出现 → 才做通用规范化。
2. 主要失败集中在证明/推导**完整性** → 才讨论 P3 或任务型 Prompt。
3. 无明显系统性缺陷 → 正式收口，不为"继续推进"而加功能。
