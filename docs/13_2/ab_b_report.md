## 3. 决定性发现：标记段语义正确率（两轮合并）

| 题型 | think=False 段含期望值 | think=True 段含期望值 |

| derivation | **11/11（100%）** | 0/9 |
| proof | **16/17（94%）** | 0/3 |
| explanation | **13/14（93%）** | 0/6 |

样例（think=False 时，标记段是干净且正确的结论）：
- proof 6009：`命题成立；矩阵 A 的行列式为 -1`（期望 -1）
- proof 6011：`命题成立，级数和为 1，S_100 = 100/101`（期望 100/101）
- explanation 6044：`真数 x 必须大于 0 … 且 log_2(8) 的值为 3`（期望 3）

## 4. 结论

1. **答案前置协议完全成功**：标记出现率 100%（实验 A 95.8%），且 think=False 的
   题（约占 55% 题次）标记段语义正确率 **93–100%**。证明「答案前置能稳定产出
   可抽取、语义正确的结论」，且不依赖抽取器改动。

2. **thinking 泄漏（25–40%）是唯一的主要障碍**：think=True 的题，标记段被模型
   复述的占位符（如 `"(Final Answer: <only write final expression>…"`）污染，
   语义正确率 0%。两轮泄漏率 39.6% / 25.0%，波动大、未被 prompt 压制语根除。

3. **少数边界**：proof 的「命题成立」模板偶尔漏写数值（6040 只输出`命题成立`）；
   个别标记段自身被 length 截断（6017 段尾部「…为 2」缺 0）。

4. **修正用户上一条提醒已得到证实**：6040 只能证明「至少存在答对却判 unknown 的
   样本」；实验 B 进一步把范围收敛为——**think=False 时模型确实答对（93–100%），
   think=True 时标记段被 thinking 污染而不可用**。三类题型的真实能力上限仍待
   实验 C 抽取器落地后由双轮 A/B 给出，不能提前断言「全部具备正确能力」。

## 5. 分流判断

按用户锁定的分流规则，实验 B 落在「标记稳定前置 + 标记后结论语义正确率明显上升
（think=False 时 93–100%）」→ **进入实验 C**：单独实现严格、有边界的标记抽取。

实验 C 的抽取器须满足（用户已列，此处确认）：
1. 跳过/识别 thinking 复述段，定位真正的「最终答案：」标记；
2. 正确处理 proof 的「命题成立，…=X」格式（取数值/结论）；
3. 补齐 8 类边界单测（单行答案、多行结论、后接完整证明、无标记、截断、重复标记、
   不等式/集合/有序元组、自然语言结论）。
实验 C 仍**只动抽取器**，不改 token（3072）、temperature、重试、开关；改完再跑
双轮冻结集 A/B + 全量单测。
