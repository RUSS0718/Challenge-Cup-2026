# 13.2 实验：3072 vs 4096 严格配对 token A/B

## 目的

F2 已证 F 安全晋升。本实验验证「token 预算不足」这个**尚未证实的强假设**——4096 的
额外窗口是否让模型写完正文、减少 length 截断导致的正文内部 self-check 污染。

## 方法（严格单变量）

同一代码提交上跑 4 轮，唯一变量是 `max_tokens` / `l0_max_tokens`：

- F 三状态解析 + C2+D Prompt + temperature=0.6 + workers=3 + retry=3 + P2/P3 关闭 +
  至多一次条件重试 + 相同数据顺序与评测脚本版本。
- 3072 双轮、4096 双轮；逐调用记录 completion tokens 与 latency（本实验前补齐遥测）。

## 质量指标（冻结集 48 题，双轮）

| 指标 | 3072 R1 / R2 | 4096 R1 / R2 |
| --- | ---: | ---: |
| length 率 | 35.4% / 41.7% | **12.5% / 22.9%** |
| thinking 泄漏率 | 33.3% / 33.3% | **8.3% / 20.8%** |
| final_response 污染 | 16.7% / 20.8% | **4.2% / 14.6%** |
| 整体准确率 | 50.0% / 54.2% | 54.2% / 50.0% |
| 宏平均 | 56.7% / 62.2% | 63.3% / 56.7% |
| derivation 两轮合并 | 90.0% | 85.0% |
| no_answer_block | 0 / 0 | 0 / 0 |

## 成本指标（逐调用，非估算）

| 指标 | 3072 R1 / R2 | 4096 R1 / R2 |
| --- | ---: | ---: |
| 主调用 completion tokens avg | 2255 / 2358 | 2333 / 2698 |
| 主调用 completion tokens P95 | 3072 / 3072 | 4096 / 4096 |
| 每题总 tokens avg | 2383 / 2422 | 2381 / 2915 |
| 每题总 tokens P95 | 3072 / 3072 | 4096 / 6299 |
| retry token 占比 | 5.4% / 2.6% | 2.0% / 7.4% |
| 估算 112 题 wall-time（均值） | 0.26h / 0.23h | 0.23h / 0.31h |
| 估算 112 题 wall-time（P95 上界） | 0.40h / 0.34h | 0.38h / 0.63h |

## 4096 晋升 Gate 逐项判定

| 门槛 | 结果 |
| --- | --- |
| 两轮 length 明显低于 3072（≤20%，至少 <30%） | ⚠️ 12.5%/22.9% 明显低于 35.4%/41.7%；R1 达 20%，R2 22.9% 略超但远低于 30% |
| no_answer_block = 0 | ✅ 两档均 0 |
| final_response 污染两轮均 ≤5% | ❌ **R1=4.2% 达标，R2=14.6% 未达标** |
| derivation 不低于 90% 附近 | ⚠️ 85%（>80% 但 <90%） |
| 整体/宏平均无稳定回退 | ✅ 波动，无一致方向 |
| 非空响应 100% | ✅ 两档均 100% |
| 每题最多 2 次调用 | ✅ max=2 |
| 平均调用不增加 | ✅ 1.02–1.06，持平 |
| 每题总 tokens 增幅 ≤25% 或重试抵消 | ✅ R1 −0.1%、R2 +20.4%（在 25% 内） |
| 6h 保留 ≥25% 安全余量 | ✅ 保守上界 0.63h << 4.5h |

## 结论：不晋升 4096，保留 F+3072

**4096 的收益是真实且显著的**：length 从 35–42% 降到 12–23%，thinking 泄漏从
33% 降到 8–21%，污染从 17–21% 降到 4–15%。这**证实了「token 预算不足」是 length
截断污染的重要成因**（不再是强假设）。

**但未达晋升门槛**：`final_response 污染两轮均 ≤5%` 不满足——R1 达标（4.2%），
R2 未达标（14.6%）。对应分流规则「4096 降低 length，但污染未稳定降到 5%」：

- 不晋升 4096；
- 不继续提高到 8192；
- 不再追加 Prompt 禁令或 thinking 关键词正则；
- **保留 F + 3072**，等官方结果决定是否接受当前边界。

## 附注（不影响结论）

- 两轮 R2 的 fallback=1 都是 6020（calculation，数值题型）模型随机失败，与 token
  档位无关。
- proof/explanation 本地 0% 仍是 judge 层「命题成立；…=X」前缀问题，非否决项，
  按人工任务完成度评价。
