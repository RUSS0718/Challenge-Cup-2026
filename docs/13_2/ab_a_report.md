# 实验 A 报告：仅补 thinking 压制语（双轮 A/B）

日期：2026-08-14
分支：`experiment/thinking-suppression`
改动：仅给 derivation / proof / explanation 三个 Prompt 加统一 thinking 压制语
（「不要输出 Thinking Process、内部计划、元分析或格式说明；直接输出面向用户的
正式答案，保留完整必要的推导/证明/解释」）。**未改**答案顺序、抽取器、token 上限、
重试策略或任何开关。

## 3. 关键发现

1. **压制语部分有效，但远未归零**：thinking 泄漏从「60/60 题次全面爆发」降到
   两轮 31% / 40%，答案标记出现率升到 95.8%。但 proof 仍有 ~65% 题次泄漏，未到
   「接近 0」。

2. **准确率几乎无提升，根因不在 thinking**：derivation/proof/explanation 仍全 0%。
   抽查发现，即使 think=False 的题（如 6040），`extracted_answer` 仍是完整证明文本
   开头（`'证明：由题设知…f(2)…'`），而非「最终答案：」后的数值。因为
   `_generate_candidates` 对 `_NON_NUMERIC_TASK_TYPES` 执行 `answer = response.strip()`
   ——**第一位阻塞是「非数值题型用完整响应当答案」，thinking 泄漏只是第二位**。

3. **choice/calculation 不降反升**（+8pp 量级）：它们走「抽取紧凑答案」路径，
   不受 thinking 泄漏影响，且压制语顺带让这两类更干净。未出现 >5pp 回退。

## 4. 晋升门槛判定（实验 A）

| 门槛 | 判定 |
|---|---|
| 三类题型不再系统性 0% | ❌ 仍 0% |
| thinking 泄漏接近 0 | ❌ 31–40%（proof 65%） |
| length 明显下降（<20%） | ❌ 35–46%，且两轮波动 |
| choice/fill/calc 无 >5pp 稳定回退 | ✅ 反升 ~8pp |
| 两轮方向一致 | ⚠️ thinking 率方向一致，length 波动 |

**结论：实验 A 未通过晋升门槛。** 它回答了一个关键问题——**压制语能阻止一部分
thinking，但不能解决「判分拿不到答案标记后内容」的问题**。

## 5. 下一步

进入实验 B（答案前置）：让三类 prompt 先输出 `最终答案：<结论>`，再给完整推导/证明，
使 `final_response` 在截断时也含明确结论；并评估非数值题型的标记抽取（判分取标记后
答案，而非完整响应）。实验 B 前不得擅自改抽取器，需先确认答案前置对 length 与
final_response 完整性是否足够。

本报告结论用于分流，不修改冻结集文件、答案或分类。
