# 13.2 晋升决策：ADOPT F + 4096（112 题双轮）

## 背景：为什么推翻「保留 F+3072」

`token_ab_report.md` 曾以「`final_response` 污染两轮均 ≤5% 未达标」为由不晋升 4096，
保留 F+3072。但 2026-08-14 14:24 的**官方隐藏集评测**（commit `174bbbb` = F+3072）给出
更强的反证：

| 官方 3072 结果 | 值 |
| --- | ---: |
| 准确率 | **4.46%**（5/112） |
| 截断（truncated_count / 请求） | **91.7%**（155/169） |
| invalid | 42（37.5%） |

官方隐藏集的推理需求远高于本地 112 短题回归集：3072 在 92% 的题上被长篇 thinking
吃光，答案标记来不及输出即截断。这一条官方硬证据压倒本地 5% 污染门槛——F+4096 比
F+3072 更合理。

## 方法（严格单变量）

唯一改动是 `AgentConfig.max_tokens` / `l0_max_tokens` 3072 → 4096。其余保持
实验分支既有默认：C2+D 输出协议 + F 三状态解析 + `policy_temperature=0.6` +
单次主调用 + 至多一次条件重试 + P2/P3 关闭。112 题 `public_regression_112.jsonl`
独立双轮，`workers=3`、`retry=3`、`timeout=60s`（沿用 token A/B 口径，避免限流）。

## 晋升 Gate 逐项判定（本次口径）

| 门槛 | R1 / R2 | 判定 |
| --- | --- | --- |
| 非空 final_response = 100% | 100% / 100% | ✅ |

| length 明显低于旧 3072 基线 | 5.4%/3.6% vs 91.7% 官方、10-18% 本地 | ✅ |

## 结论：ADOPT F + 4096

- length 从官方 91.7% 降到本地 3.6–5.4%，从根上解决「答案被截断」的第一阻塞。
- 准确率 83.9%/84.8%，不低于 F+3072 的 83.9%，无跨轮回退。
- 成本受控：平均 1.0–1.01 次调用、每题总 token 约 1907–1954（P95 3799–4096），
  估算整轮 wall-time 约 11 分钟，远低于 6 小时安全余量。
- `final_response` 污染两轮均 0%，未重演 4096 冻结集实验里 R2=14.6% 的边界。

默认 `max_tokens` / `l0_max_tokens` 由 3072 改为 4096，同步更新 README 配置表、
`AgentConfig` 注释与两处默认值断言测试。
