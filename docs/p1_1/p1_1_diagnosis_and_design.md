# P1.1 针对稳定错题 0/1/2/10 的通用单变量设计

日期：2026-07-29

## 1. 诊断

| idx | 题型 | 观察 | 根因类别 |
| --- | --- | --- | --- |
| 10 | 代数多解 `x^2-1=0` → 金标 `-1, 1` | 实机输出 `x = 1, x = -1`，算对但表面串不等于金标 | **表示不兼容**（可通用修复） |
| 0 | 有限域 | AF 三轮全错、有有效候选 | 硬推理 |
| 1 | 反函数导数/积分 | 同上 | 硬推理 |
| 2 | 留数 | 曾抽到格式污染串；也有有效候选但答错 | 硬推理 / 偶发污染 |

结论：四题中**唯一有证据、且不损普适性**的可修复点是 **无序多根数值答案的规范化**。  
0/1/2 需要更强推理，不在本轮“单变量表面修复”范围。

## 2. 单变量改动（已实现，待全量复评）

在 `normalize_answer` / `answer_equivalence` 中，仅对满足下列**通用**条件的答案做无序数值集合规范化：

1. 含显式多分隔（`,` / `或` / `or` / 集合花括号内多值）
2. 每段在去掉可选 `变量=` 前缀后均为可解析有理数
3. **不**处理有序元组 `(a,b,...)`、不等式、非数值代数式

输出形如排序去重后的 `-1,1`；`final_response` 优先使用 `normalized_answer`。

**明确不做**：idx 硬编码、学科分支、只为 idx10 改 Prompt、放宽所有字符串匹配。
