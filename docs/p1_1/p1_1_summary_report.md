# P1.1 无序多根数值规范化（通用单变量）

日期：2026-07-29  
状态：完成 — 决策：**ADOPT**  
约束：无题号/学科特判，只处理可解析有理数的无序多值答案。

## 动机

- 目标题簇 0/1/2/10 中，仅 idx 10 被证实为“算对但表示不兼容”（`x=1,x=-1` vs `-1,1`）。
- 0/1/2 为硬推理，本轮不牺牲普适性去做特化。

## 改动（唯一变量）

1. `normalize_answer`：对 `,` / `或` / `or` / 花括号多值且每段为有理数的答案，去掉可选 `var=` 后排序去重。
2. 不碰有序元组、不等式、非数值式。
3. `answer_equivalence`：多根数值集合可证不等时返回 `NOT_EQUIVALENT`。
4. `final_response` 优先输出 `normalized_answer`。

## 结果

| 轮次 | 准确率 | idx10 | 0/1/2 | 超时 | 空响应 |
| --- | ---: | --- | --- | ---: | ---: |
| P1 AF 基线三轮 | 12 / 15 / 12（~13/23） | 0/3 | 0/3 | 0 | 0 |
| P1.1 main | **15/23** | True | 全 False | 0 | 0 |
| P1.1 rerun1 | **18/23** | False* | 全 False | 0 | 0 |

\*rerun1 的 idx10 错误属模型当轮未给出正确数值集合，非规范化回退；main 上 idx10 已修通。

- 两轮均 **> 13/23**，满足采纳门槛。
- 新基线约 **16–17/23**（均值 16.5/23 ≈ 71.7%），相对 P1 ~13/23 约 **+15pp**。

## 决策

**ADOPT** 通用多根规范化进入默认路径（代码已在 `user_agent.py`）。
