# P1 新基线错误重分类（2026-07-29）

## 输入
- 数据源：`docs/p0_3/p0_3_token_1024_main_2026-07-28.json`、`p0_3_token_1024_rerun1_2026-07-29.json`、`p0_3_token_1024_rerun2_2026-07-29.json`
- 基线：max_tokens=1024，三轮准确率 12/11/10，均值约 11/23 (47.8%)

## 分类口径
1. 模型求解错误
2. 有效答案未被抽取
3. 答案组/审核选择错误
4. 全候选无效

## 三轮交叉结果
- 始终错误（3/3）：idx 0,1,2,10,15,20,22
- 高不稳定错误（>=2/3 且存在正确轮次）：idx 9,11,19,21
- 其他：其余题至少一轮正确且未形成稳定最高收益簇
- 抽取链路信号：三轮中仅 idx 2 在 main 出现一次 `answer_not_extractable`，其余错误题未出现候选拒绝或 fallback；`finalization_status` 全部为 `selected`

## 结论
按数量和可修复性，最高收益类别是**模型求解错误/输出收敛不稳定**，不是抽取器、答案组或全候选无效。
因此 P1.1 先做最小 Prompt A/B，优先降低格式说明污染和冗长输出；只有当该 A/B 无收益时，才评估更重的求解/裁决改动。
