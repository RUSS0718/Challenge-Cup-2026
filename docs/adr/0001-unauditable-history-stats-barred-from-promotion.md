# 不可复核的历史统计不得进入晋升证据链

Status: accepted (2026-08-27)

仓库中无法从落盘工件复核的历史实验数字(转述性历史统计),不得进入任何
晋升叙事、累计显著性计算或默认路径决策;只能当作寻找原始工件的线索。
发现此类数字时,处理顺序是:恢复原始工件 → 逐题重建并核对 → 恢复失败则
另立 fresh 编号重做,而不是继续累加。同期事故:refine 战役的 b=12,c=4
最初只剩口头转述,`skipped_exact_refine_extension.json` 甚至错误记录了
"每轮 96 题源不存在"。

## Considered Options

- 继续把新窗口加到转述数字上:被否决——审计黑洞,且可能把不可复核数据
  带进正式门甚至官方提交叙事。
- 直接丢弃历史数字、无条件重来:被否决——若工件可恢复,重建比重跑便宜
  且保留连续性(本例最终走通了恢复,见 ADR-0002)。

## Consequences

- 实验完整性现在依赖工件归档纪律:每次战役必须有 manifest + 逐题
  answers 落盘,临时目录(tmp/)里的结果要及时归档。
- "净增/总题数"分母必须写明是配对数(轮数×题数),避免把重跑追加行
  误当独立题数。
