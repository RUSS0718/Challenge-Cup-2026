# 提升计划最终阶段审计（2026-08-18）

## 已完成的实验

1. 60 题公开来源中等冻结集与本地等价判分。
2. 确定性求解器扩展、独立复核和两轮本地 Gate。
3. 397B baseline 与 RAG 双轮真实 A/B。
4. 397B baseline 与确定性求解器集成双轮 A/B。

## 决策

- `intern-s2-preview-397b`：作为本地后续实验模型，预检和 60 题 baseline 有效。
- RAG：双轮准确率均下降（−3.33pp、−8.33pp），P95 延迟明显增加，拒绝默认晋升。
- 确定性求解器：两轮总准确率各提升约 1.67pp，调用数下降；但相对 baseline 真正从
  `unknown/incorrect` 救回的题只有 5 个，低于 10–15 门槛，拒绝默认晋升。
- 112 题确定性覆盖为 0，说明没有已知回归风险，但不能弥补新增命中不足。
- DSL、自一致性、P2/P3：按依赖条件不启动；RAG 未形成净收益，且确定性工具未达到默认晋升门槛。
- 默认配置：保持 RAG 与确定性求解器关闭；不提交未经 Gate 证明的路径。

## 总结

本轮完成了可复现的能力建设、双轮真实评测和独立否决。没有任何新能力满足默认晋升条件，
因此最终交付是“实验资产与明确拒绝结论”，而不是未经证据支持的默认提分改动。
