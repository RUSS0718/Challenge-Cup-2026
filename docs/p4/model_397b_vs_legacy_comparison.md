# 397B 与旧模型别名对比（2026-08-18）

## 结论

在同一份 60 题中等能力冻结集、相同主要预算下，旧别名
`intern-s2-preview` 两轮均为 **32/60（53.33%）**，高于显式 397B
`intern-s2-preview-397b` 的 **29/60（48.33%）** 与 **30/60（50.00%）**。

按两轮平均，旧别名比 397B 高 **4.17 个百分点**，UNKNOWN 率低 **4.17 个百分点**，
P95 延迟低约 **9.22 秒**；代价是平均模型调用数高约 **0.033 次/题**。

因此，本冻结集上的轮级证据支持：**旧别名本轮表现优于显式 397B**。这只是模型对照结论，
不等于官方隐藏集成绩，也不自动授权切换提交默认配置。

## 证据边界与后续决策

- 两个旧模型 JSON 都有 60 条记录、0 超时、0 空响应、0 failed item；第一轮进程的非零退出
  仅由 Windows 控制台 GBK 无法打印完整 JSON 引起，输出文件已完整校验，第二轮已显式使用 UTF-8。
- 旧别名两轮准确率相同，397B 两轮均低于旧别名；方向一致，但差距只有 2–3 道题/轮，仍不宜
  把它表述为官方模型能力的普遍定论。
- 本轮只回答“哪个模型在该冻结集 baseline 上更好”，没有测试 RAG、确定性求解器、P3 或默认配置
  切换；这些能力继续保持原有 Gate 边界。
- 在确认官方 API 对 `intern-s2-preview` 的实际模型身份、可用性和提交约束前，不根据本报告自动
  改写 `DEFAULT_MODEL`、提交或推送。
